Anthropic API key
Every tracker can pull a spoiler summary for an issue, a chapter or a whole omnibus. Those are generated on demand and need your own Anthropic API key. The key is saved in this browser only, is sent nowhere except api.anthropic.com, and works across every subject — set it once here.
Keys come from console.anthropic.com. The X-Men tracker’s 27 arc digests are written into that page and keep working with no key at all.
Start over
Wipes every subject’s read and skipped marks, the Keep Reading rail and anything you’ve cleared off it. Progress is saved in this browser on this device only and never syncs, so another computer — or another browser here — keeps its own separate reading and is not touched by this. Your API key and any saved summaries stay. There is no undo: back up from a tracker’s Back up button first if you want to keep what you have.
